# Hints

Stuck? Open the file for the area you are working on and read **one tier at a time**:
Nudge first, then Technique, then Near-spoiler. Using a hint does not cost your
fix-and-test score. Getting unstuck is the point.

The flag is only the easy half. Whichever tier gets you moving, still do the fix and
write the test that proves it.

| If you are stuck on... | Open |
|---|---|
| error responses or missing headers | error-and-headers.md |
| logging in, tokens, or the admin flag | login-and-tokens.md |
| the customer search | customer-search.md |
| reading an account, or your profile | accounts-and-profile.md |
| a secret, or a flagged package | secrets-and-packages.md |
| the continue / redirect endpoint | continue-redirect.md |
| downloading a statement | statement-download.md |
| transferring money | transfers.md |
